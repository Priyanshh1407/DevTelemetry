=================================================================
DEVTELEMETRY DEMO COMMANDS CHEAT SHEET
=================================================================

1. INITIAL SETUP (Only needed once, or if opening a new terminal)
-----------------------------------------------------------------
Activate the virtual environment (if using Git Bash on Windows):
    source venv/Scripts/activate

Activate the virtual environment (if using PowerShell on Windows):
    .\venv\Scripts\activate

Install dependencies:
    pip install -r requirements.txt


2. GENERATE SYNTHETIC DATA
-----------------------------------------------------------------
This creates the fake historical data for the team.
Command:
    python data/seed.py


3. RUN THE CORE AGENT (Scoring & Insights)
-----------------------------------------------------------------
This runs the main processing engine that calculates efficiency 
scores and calls the Gemini API to generate personalized guides.
Command:
    python main.py


4. START THE DASHBOARD (Web Interface)
-----------------------------------------------------------------
This spins up the web server so you can view the leaderboard 
and the generated AI guides.
Command:
    python -m uvicorn api.main:app --reload

Once running, open your web browser and go to:
    http://localhost:8000
